### 🎙️ UVA RadioPlay

Automatización de radio para Windows: tu emisora al aire las 24 horas, sonando como una profesional.

- **AutoDJ 24/7** con relojes, reglas de rotación y pauta diaria
- **Tandas, cuñas y pisadores** a su hora, cada X minutos o cada X canciones
- **Streaming incluido**: Shoutcast v1/v2 en MP3 y AAC+, a varios servidores a la vez
- **Procesador de audio**, botonera F1–F12 y reportes para anunciantes
